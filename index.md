# Политика конфиденциальности приложения «Съел»

Дата последнего обновления: 8 ноября 2026 года.

## Коротко

Приложение «Съел» не требует регистрации, не содержит рекламы и не собирает
персональные данные. Всё, что вы вводите, хранится только на вашем устройстве.

## Какие данные обрабатываются

**Данные о питании.** Продукты, блюда, записи дневника, норма калорий и настройки
оформления хранятся в локальной базе данных на устройстве. Приложение не имеет
собственного сервера и не передаёт эти данные куда-либо. При удалении приложения
эти данные удаляются вместе с ним.

**Камера.** Доступ к камере используется исключительно для распознавания штрихкода.
Изображение обрабатывается на устройстве, не сохраняется и не отправляется.

**Сеть.** Если отсканированного штрихкода нет в локальном справочнике, приложение
отправляет в открытую базу Open Food Facts (world.openfoodfacts.org) только номер
штрихкода, чтобы получить название и пищевую ценность продукта. Никакие иные
данные, включая сведения о вашем дневнике, не передаются.

**Персональные данные.** Приложение не запрашивает имя, телефон, почту, геолокацию
и не использует сторонние SDK аналитики или рекламы.

## Разрешения

- `CAMERA` — сканирование штрихкодов.
- `INTERNET` — поиск продукта по штрихкоду в Open Food Facts.

Оба разрешения необязательны для основной работы приложения: дневник и справочник
полностью работают офлайн.

## Дети

Приложение не предназначено специально для детей и не собирает данные о них.

## Изменения

Актуальная версия политики всегда доступна по этому адресу. При существенных
изменениях дата обновления в начале документа будет изменена.
